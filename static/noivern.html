Noivern.

An audio detection application written in Rust and designed to run on Raspberry Pi and Linux systems.

Rust Raspberry Pi Linux Audio CLI

About the project

Noivern is a lightweight audio detector built to monitor microphone input and identify changes in sound activity.

The project explores real-time audio capture, signal analysis, command-line interfaces, logging, and background execution on Linux.
